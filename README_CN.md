# Maya Playblast Tools

[English](README.md) | 中文

Maya 动画拍屏工具  
支持 H.264 / H.265 / AV1 编码的高质量视频，支持画质档位、分辨率控制与场景音频混入。

支持版本：Maya 2022 / 2023 / 2024

## 安装

### 拖拽安装（推荐）

1. 打开 Maya（2022 / 2023 / 2024）
2. 将项目中的 `install.py` 文件拖入 Maya 视口
3. 等待自动安装完成（首次使用需要联网，用于下载 FFmpeg）
4. 安装成功后，按钮会直接出现在时间滑块右侧，无需重启 Maya

### 手动配置（可选）

如果拖拽安装不生效，可将 `modules` 目录加入 Maya 的 `MAYA_MODULE_PATH` 环境变量，然后重启 Maya。

## 使用

### 基本操作

| 操作 | 功能 |
|---|---|
| 左键点击按钮 | 弹出保存窗口，按当前设置输出视频 |
| 右键点击按钮 | 打开输出选项菜单 |

### 输出选项（右键菜单）

| 选项 | 说明 |
|---|---|
| Auto Play | 输出完成后自动播放视频 |
| Sound | 混入时间滑块上加载的音频（场景无音频时提示并输出无声视频） |
| Container | 容器格式：MP4 / MKV / MOV |
| Video Codec | 视频编码：H.264 / H.265 / AV1（随容器自动过滤） |
| Frame Format | 中间帧格式：JPEG / PNG |
| Resolution | 分辨率：常用预设 / 视图尺寸 / 渲染设置 |
| Quality | 画质：High / Medium / Low |
| Scale | 渲染百分比：25% / 50% / 75% / 100% |
| Preset | 预设方案：应用、保存、删除（当前选项会自动记忆） |

### 提示

- 视频保存后，临时帧序列会自动清理，无需手动处理
- 保存位置会被记住，下次打开默认跳到上次目录
- 音频来自 Maya 时间滑块上加载的音频（时间滑块 > Sound 菜单导入）
- 右键菜单内可以连续调整多个选项，点击菜单外的区域或选择 Playblast 才会关闭菜单
